# Meu Perfil Acessível

Este é um projeto simples de página web de perfil estudantil fictício desenvolvido com o objetivo de aplicar boas práticas de semântica e acessibilidade estrutural utilizando **HTML5** e **CSS3**.

## 🚀 Tecnologias Utilizadas
- HTML5 (Uso de tags semânticas e ARIA)
- CSS3 (Variáveis nativas, Flexbox, Grid e Media Queries)

## ♿ Boas Práticas de Acessibilidade Aplicadas
1. **Estrutura Semântica**: Utilização correta de `<header>`, `<main>`, `<section>` e `<footer>`.
2. **Textos Alternativos**: Inclusão de atributo `alt` descritivo na imagem do avatar.
3. **Alto Contraste**: Seleção de cores com taxas de contraste adequadas para facilitar a leitura.
4. **Hierarquia de Títulos**: Organização lógica de títulos (`<h1>` a `<h2>`) vinculados por `aria-labelledby`.
5. **Navegação por Teclado**: O elemento de botão possui estados visíveis de `:focus` e `:hover`.
6. **Responsividade Amigável**: Uso de unidades flexíveis e Breakpoint CSS para perfeito funcionamento em computadores e celulares.
